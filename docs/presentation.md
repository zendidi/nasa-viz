# Présentation du projet

Le document de présentation de NASA Viz est en ligne (Claude Docs) :
https://claude.ai/artifact/9XaRr9qKhxyxzr8dVPHy5a — « NASA Viz — présentation de l'outil ».

Écrit le 2026-10-21 pour une relecture par un astronome et un astrophysicien. Contenu : l'outil en
bref, les sources de données, les deux modes (Lisible / 100 % réel), la précision mesurée contre
JPL Horizons (graphique avant/après), le modèle physique et les choix assumés, les limites connues,
les questions pour les experts.

Les chiffres datent du 2026-10-21. Si le code a changé depuis (précision, sources, modèle), mettre
le document à jour (le relire avec les outils Docs) plutôt que d'en créer un second.
