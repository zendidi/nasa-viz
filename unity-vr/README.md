# Unity VR — NASA Viz

Projet Unity non initialisé ici (les fichiers binaires/meta Unity ne se scaffoldent pas à la main).

## Pour démarrer
1. Créer un nouveau projet Unity 6 (template 3D URP) dans ce dossier via Unity Hub
2. Remplacer le `Packages/manifest.json` généré par celui fourni ici (ou fusionner les dépendances)
3. Project Settings → XR Plug-in Management → activer OpenXR, profil Quest
4. Créer les scripts listés dans ARCHITECTURE.md (racine du projet) sous `Assets/Scripts/`
